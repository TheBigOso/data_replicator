BRANCH · what each method can say (and what it can't)
Row counts
COUNTS EQUAL / COUNT MISMATCH — no classes, no match rate, no repair. The sync report's first number.
Bulk
IDENTICAL / DIFFERENT — checksum only; knows that tables differ, not which rows → composed re-run hint.
Composed
Full inventory — missing on target / only on target / different, match rate, diff file, repair enabled.
Any method
Structure check runs first — a mismatch short-circuits that table with the column named (column TIER missing on target), never garbage row diffs.
Verdict line
IN SYNC · DRIFT DETECTED · STRUCTURE MISMATCH — direction-independent; active filters and restrict always named.
